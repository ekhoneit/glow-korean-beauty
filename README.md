# Glow Korean Beauty - Monorepo

Complete authentic Korean Skincare & Cosmetics E-commerce platform built with Next.js, Express, Prisma, and MySQL.

## Structure
- `glow-frontend/`: Next.js 15 customer storefront (SSR, Tailwind CSS, Framer Motion)
- `glow-admin/`: Next.js admin management portal (POS, Analytics, Inventory, CMS)
- `glow-server/`: Node.js & Express REST API with Prisma ORM & MySQL
